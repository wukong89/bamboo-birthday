# 竹妹儿的生日礼物

一份可直接部署到 GitHub Pages 的静态生日网页。开发者署名：沐清铖。

## 体验结构

1. 打开香槟金封蜡的信封。
2. 沿风筝线回到那只风筝。
3. 看见两盏灯下一起备考的日子。
4. 沿着两条靠近的路线，走向彼此。
5. 翻阅棉袄和新衣服留在冬日里的照顾。
6. 走过六张卡片组成的味觉地图。
7. 回到人民公园、定国湖、接送、散步和电动车上的普通日子。
8. 看到留给未来的话。
9. 收下单烛生日蛋糕上的祝福。
10. 在页面上寻找一颗不显眼的小星星，打开第二封信。

页面不依赖后端、登录、API Key 或外部图片。新增书桌、双城路线、棉袄、六种食物等景物均由本地 SVG 绘制，音乐与网页均使用相对路径。

## 本地预览

在这个目录打开终端，运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

不要在微信内置浏览器里做最终验收。建议用 iPhone Safari、Android Chrome 和桌面 Chrome 各看一次。

## 操作说明

- 点击「打开这份心意」：信封打开并尝试在真实点击事件中启动音乐。
- 右下角音乐按钮：暂停或继续播放。默认音量为 `0.4`，歌曲循环播放。
- 点击「收下今天的祝福」：三组烟花、礼花纸屑和星光动画出现，蛋糕烛光增强。
- 点击任意美食卡片：卡片会保留轻微强调状态，再次点击可取消。
- 隐藏彩蛋：生日章节右下方、风筝线末端附近有一颗低亮度小星星。
- 秘密信笺底部「回到生日祝福」：返回原页面位置。
- 秘密信笺也支持按 `Esc` 关闭。

## 部署到 GitHub Pages

1. 将本目录内的全部文件放到 GitHub 仓库根目录，或本仓库为 Pages 指定的发布目录。
2. 在 GitHub 仓库的 `Settings → Pages` 中选择发布分支与目录。
3. 等待 Pages 构建完成，打开生成的 HTTPS 地址。
4. 不要修改仓库里与本项目无关的现有配置。

页面使用相对路径，因此部署在当前仓库根目录或项目子路径下都能加载。

## 音乐与公开部署提醒

`assets/spring-rain.mp3` 来自用户提供的本地文件，格式已确认为 MP3，时长约 291.7 秒。公开仓库和公开 GitHub Pages 可能允许他人直接下载这首歌；若仓库公开，请先确认音乐再分发权限，或改用你有权公开的本地版本。不要把公开网址发给不希望看到内容的人。

## NFC 标签写入

1. 先完成 GitHub Pages 部署并确认 HTTPS 网址可以打开。
2. 在 Android 或 iPhone 上安装支持 NDEF 的 NFC 工具，例如 NFC Tools。
3. 选择「写标签 / Write」。
4. 添加一条「URL / 网址」记录，填入完整的 Pages 地址。
5. 将手机靠近可写的 NDEF 标签，确认写入成功。
6. 用另一部手机贴近标签，验证会打开同一页面。
7. 如需修改网址，先确认标签可重写，再覆盖原记录。

建议使用 NTAG213、NTAG215 或 NTAG216 等常见 NDEF 标签。NFC 只负责分发网址，网页本身仍需要联网加载。

## 兼容与无障碍

- 适配 320、375、414、768 像素及桌面宽度。
- 已设置 `overflow-x: clip`，防止横向滚动。
- 支持 `prefers-reduced-motion: reduce`，此时动画缩短或停止。
- 所有交互控件都有可见键盘焦点和 44 像素左右的触控区域。

## 素材替换

若要换成你们自己的照片，建议把压缩后的 JPEG 或 WebP 放进 `assets/`，并在 `index.html` 对应的 SVG 画面位置替换为 `<picture>` 或 `<img>`。不要用未经授权的人物照片冒充真实合照。
